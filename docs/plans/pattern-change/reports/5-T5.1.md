## Deviations

- **Joyride v3 kept.** I did not need the Popover fallback. I made three adjustments to Joyride:
  - Joyride paints its floater at `zIndex + 1` and its overlay at `zIndex`, so I pass `zIndex: 127` with `styles.overlay.zIndex: 126`, and `tour.css` pins both layers to the tokens.
  - The spotlight `fill` is set from CSS (`--tour-dim`), because the SVG attribute can't resolve a CSS variable.
  - Joyride's scroller is replaced by a rect-delta `before` hook (zoom-safe).
- **The deep link works for every tour**, not only first-review: `?tour=<id>` on the tour's own route or surface. T5.2 should link "Page tours" this way, because calling `start(id)` from `/learn` and then navigating gets stopped as "left the surface".
- **Chip eligibility = first target AND at least half of the targets.** A generic rule, so Reviews needs no special case. Spec PC-38 says "first target exists (Reviews: once the queue has rows)", and on the empty page `reviews-start` alone exists.
- **"First visit" = the visit that first shows the chip.** The tour is marked seen as soon as the chip is displayed, not when it is clicked or dismissed. Dismiss (×) hides it for the visit; it is already seen.
- **The review chip is hidden on the sample review and on read-only reviews.** The spec calls for "the user's own review", and a signed workbook has no Sign or decision targets.
- **Esc skips the tour.** The spec is silent on this. The takeover's Esc guard already ignores Esc while a `[role=dialog]` other than `.run` is open, and the card is one.
- **`TourChip` (molecule) reads stores and imports `organisms/tour/useTourTargets` + `tour.css`.** The stub's contract is `{ tourId }` only, so it must read the stores itself.
- **The Back button was added** to the card (spec: Skip / Next) because `useTourStore.back()` exists. It shows from step 2.
