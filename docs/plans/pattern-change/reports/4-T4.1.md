### Prototype hook (dev only, `process.env.NODE_ENV !== "production"`)

- `?lock=<kind>` on `/dashboard`, where kind is `approval`, `approval-unbooked`, `approval-reviewer`, `credits-short`, `credits-zero`, `credits-reviewer` or `role`. It waits for the org and users to load, removes `lock` from the URL with `router.replace` (so a checkout `return` never carries it), then opens the variant.
- `window.__parachuteLock(kind)` opens the same variants without navigating. The current `document.activeElement` becomes the opener, which the focus checks rely on.
- The previews may force booked or not booked, and admin or reviewer, so every variant shows on one Harbor persona. When the org has no `callBookedAt`, the booked date falls back to tomorrow at 10:00 AM ET. The preview's `onRunOnly` shows a toast ("Preview: Technical review would start now").

## Deviations

1. **The credits dialog for admins is DS `size="md"` (560 px), not `sm`.** At 440 px the three actions ("Back", "Run Technical only (1 credit)", "Add 1 credit") wrap onto two rows. Board 2 draws this dialog at 600 px. Every other variant is `sm`.
2. **The short variant has both radios and two action buttons, as the spec table and the board do.** Picking a radio makes its own button primary and the other one outline. The default is "Add N credits" as primary. When `onRunOnly` is absent, only the Add option card is drawn.
3. **The reviewer approval variant's "Ask Dana" shows a toast ("Note sent to Dana") and closes.** No record type exists for "nudge the admin about the call". `CreditRequest` is for credits, so I didn't reuse it here. See Open items.
4. **The reviewer credits title is always "You need N more credit(s)"**, including at zero balance (§5.5 gives the reviewer only that one title).
5. **"Already asked" state** (not in the table): "You already asked Dana", "Dana Reyes has your request from <date>. You'll see it on Billing when credits are added." Spot 15, "Got it". This follows the brief's "say so instead of a second ask".
6. **The DS header is kept but loses its bottom rule** (`.lock-dlg > header`), so the × floats above the art as on board 1. The accessible name is a generic DS `title` ("Waiting on setup", "Not enough credits", "Only admins can buy credits"). The visible h2 in each body carries the specific wording.
7. A JSX text run that began with a space right after `{expr}` on a wrapped line lost the space in the build ("Dana Reyesgets"). Those two lines are now template strings, and the flow checks the sent copy.
