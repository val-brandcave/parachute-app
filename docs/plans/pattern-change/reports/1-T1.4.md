## Deviations
- The demo accepts any 6 digits, so `000000` is the "wrong" code (prototype-only constant `WRONG_CODE`).
- Hand-off encoding on Keycloak pages: `from:"signup"` = arriving forward, `from:"verify"` arriving on a KeycloakFrame = arriving back (dir -1). Verify success sets `from:"verify"` too, but that is consumed by /welcome, not a KeycloakFrame.
- `shakeKeyframes` is not exported by lib/motion.ts; inline `x:[0,-6,6,-6,6,0]` with `dist.shake` used.
- Check "draw" is a clip-path wipe on the Icon `check` (no inline SVG allowed), not stroke-dashoffset.
- Content motion.div is remounted (key) when a hand-off is found, so form state resets once right after mount.
- One `eslint-disable react-hooks/set-state-in-effect` in KeycloakFrame (one-shot sessionStorage read, cannot run in SSR).
- (auth)/layout.tsx not modified: nothing needed there.
