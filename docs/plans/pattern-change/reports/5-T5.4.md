## Deviations

1. **Lakeside and Cedar are not retired yet.** The earlier flows assert their identities ("until Lakeside is confirmed", "Ask Carla", Cedar's 1 credit, approver on Cedar). So a legacy alias (`/demo/<id>`, `?persona=`) keeps the old persona's seeded identity and leaves rows untouched (exactly the old behaviour; also keeps t4_4's cross-persona request hand-off). Everything else — popover axes, presets picked in the popover or Index, pill states — stages on `org-hcb`. The popover footer names a legacy persona while one is active, and Reset org resets that org to its seed. Retire them when those flows are rewritten.
2. **Re-keyed fixtures come from Meridian.** Lakeside and Cedar never had review rows, so `busy` re-keys Meridian's queue.
3. **Pill sits bottom centre**, not top centre (coordinator note; see Placement). Spec §6 / draft §3.1 say top centre: update them if this sticks.
4. **Page-state pick resets modifiers and may start from the seed scenario** (see useProtoView above) so each segment lands in one click. Popover axis changes keep the plain merge.
5. **Reset tours and celebrations** clears prefs `toursSeen` + `celebratedBy` for the current user only (chips read on mount; applies on next visit). **Replay arrival** additionally clears that user's `celebratedBy.onboarding` and welcome dismissal by `usePrefsStore.setState` + the same localStorage keys, because prefs has no single-kind unmark.
6. Segment tips are a local tip under the pill: the house `Tooltip` places only top/right and sits on tier 160, under the pill.
