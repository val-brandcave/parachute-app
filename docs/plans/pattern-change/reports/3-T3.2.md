## Deviations

- Hero heading stays "Credit balance" (admin) / "Team balance" (reviewer); the board's "Balance" label not used.
- Reviewer overview gets the hero tone/chip and the admin line only; the request-credits note field and "Requested" tracker are T4.4.
- Invoiced hero is still the three-card `InvoicedStrip` (now priced at `INVOICED_CREDIT_USD`), not the board's single hero with Invoices/by-person table.
- Locked Add credits is an outline button (the global `[aria-disabled]` style dims a primary too much); `LockDialog` is a stub until T4.1, so the click is wired (`openLock({kind:"approval"})`) but unverifiable.
- Date wording in new copy is en-US ("Nov 17"); older parts of the page keep en-GB.
- Reviewer "My usage": donut of own credits only, no by-person card.
- Invoiced Usage feeds `usageByType`/`usageByPerson` with spend entries synthesised from `buildUsageLines` (invoiced reviews), so there is still one derivation.
