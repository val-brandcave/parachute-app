## Deviations
- `+autoReload` on low/short flags the pack5 purchase `auto: true` instead of adding a row, so balances stay 3 / 1.
- `+expiring` adds pack5 @ now-359d plus a 2-credit debit (3 left), so the balance rises by 3.
- Bonus modifier moves the trial grant for fresh/trial/low/short/zero (open = now-2d, ending = now-12d, closed = now-15d); `fresh` with bonus open stays at now-1h. Healthy ignores it.
- Setup "8 steps" is not defined in the repo once `sample_review` goes: I counted first_review, sign_workbook, bank_policy, security_pack, checklist, layout, invite, tutorial (account is extra and always done). mid = first_review + invite.
- Normalization extras: prospect/verified force held/empty/hidden; youconnect is applied before pending; invoiced sets bonus closed and card -> invoice; held turns off autoReload/expiring.
- Registry `Audience` uses `self_serve` (not draft's `plg`); Preset has optional `status`.
