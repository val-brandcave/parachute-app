## Deviations

- **Headline for orgs that can't earn** (payg without a trial grant, closed window, invoiced): "Finish setting up <Org>." The spec only defines the trial headline; "Your trial includes…" would be false for these.
- **Pending without a booked call**: headline "Get Lakeside ready while Realwired confirms it." (spec only has the booked wording).
- **"Start tour" with no own review** also opens the role-style lock ("Run a review first"), same as "Sign workbook" — otherwise it would land on an empty `/reviews`.
- **Done admin-only rows for non-admins** (e.g. reviewer, done "Invite") show no button; done rows aren't actions they can take.
- **"First non-sample review"** = first in reviews-store order (gives 220 Commerce Way for Harbor, as the seed intends); the earliest by `createdAt` would be the completed 18 Lighthouse Rd.
- **`home-grid`** lives in `globals.css`, not `home-cards.css` (nothing to drop there); Get started simply no longer uses it. See requests.
- **`setup-checklist.css`** replaced by `get-started.css` rather than stripped (its only consumer was deleted).
- Section card sub-copy while pending reads "until your organization is confirmed" (from `lib/setup-steps.ts`), not "until Harbor is confirmed".
- The page `h1` takes programmatic focus without a visible ring (it is a landmark, not a control).

## Fix round 1

### What changed

1. **Arrival timing (`home/useArrivalCelebration.ts`, `GetStarted.tsx`).** The hook now takes `ready`, which is the page content being on screen (not the skeleton) and the user not being redirected away. `takeArrival()` runs once on mount and clears sessionStorage straight away. The arrival is kept in component state, which survives a strict-mode remount, so the module-level `pending` is gone. 200 ms after `ready`, the hook flips `landed`, which brings in the welcome line, and fires `celebrate("onboarding")` for a self-serve arrival, both at the same moment. If the user leaves early nothing replays, because the mark is already cleared.
2. **AllDone locked "Start a review".** It now uses the SetupRow lock pattern: a `useId` reason span, `aria-describedby`, a trailing `hourglass-high` icon, a click that calls `openLock({ kind: "approval" })`, and no `disabled`.
3. **Dead code.** Deleted `home/HcFrame.tsx` and `home/home-cards.css`. The grep showed `GuideVideo.tsx` (kept per spec §5.2) still uses the `.hc-player`, `.hc-poster`, `.hc-ctrls` and `.hc-seek` rules. Those were only reachable through HcFrame's import, so they moved to `home/guide-video.css`, imported by `GuideVideo.tsx`. All other `hc-*` rules were dropped.
4. **Flow (`app/scripts/flows/t2_1_get_started.py`).**
   - **Primaries:** exact counts per section per persona: trial-admin `[1,1,1]`, pending-admin `[0,1,1]`, reviewer `[1,0,0]`, approver `[0,0,0]`.
   - **Ask buttons:** exact counts (reviewer 4 "Ask Dana", approver 2 "Ask Carla").
   - **Lock proof:** a dev-only probe (`home/useLockProbe.ts`, compiled out of production, called in `GetStarted`) mirrors the lock store's reason kind onto `<html data-lock-kind>`. Pending-admin asserts `approval` after the locked click and checks the `aria-describedby` text ("Opens when Lakeside Valuation is confirmed"). Approver asserts `role` after "Start tour" with no own review.
   - **Welcome line:** uses the interstitial's `parachute:arrival` sessionStorage mark. The cases are: self-serve arrival shows it; reload hides it; enterprise arrival hides it; Dismiss hides it and the dismissal persists across a later arrival.
   - **Bonus ending / closed and invoiced:** set by editing the mock store in localStorage (Harbor's trial-grant date; Harbor's billing set to invoiced with `salesRequested`), then restored. Assertions:
     - Ending: "2 days left to earn", amber, pills kept.
     - Closed: "Bonus window closed", no pills, rows still `[1,1,1]`.
     - Invoiced: no pills, "Finish setting up Harbor.".
     - Approver (Cedar, no trial grant): no pills.
   - **Pending copy:** the held sub now reads "until Lakeside is confirmed" (the coordinator's `sub(kind, pending, org)`).
5. **Content entrance** uses `dist.enter` (12 px); the welcome line keeps `dist.lift` (8 px).
6. **CSS motion.** `globals.css` has no `--ease`/`--dur` custom properties, so the two transitions stay, with a comment naming the lib/motion values (`dur.quick` + `ease.standard`), plus a `prefers-reduced-motion` guard: the chevron and resource cards don't animate. `EarnedToastHost` waits `stagger.gap * 1000` ms instead of a bare `60`.
7. **Pending card grid** is now `minmax(0, 3fr) minmax(0, 2fr)`, with no px cap.
8. **`useFirstOwnReview.ts`** has a comment: "first" = reviews-store order (the seed intends 220 Commerce Way).
