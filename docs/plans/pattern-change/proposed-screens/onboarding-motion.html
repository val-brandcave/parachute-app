How the app builds this. The app already ships framer-motion (^12.40), so no new motion dependency: layout on the card and side panel gives the height and position glide, AnimatePresence mode="wait" runs each content exit before the next enter, and useReducedMotion switches to the reduced-motion branch. Confetti uses canvas-confetti (about 6 KB). This page reproduces the same timings with the Web Animations API and an explicit FLIP (measure old and new size, animate width and height), so the numbers carry over one to one. The speed control scales every duration and delay; confetti physics is scaled by approximation (velocity, decay, gravity and lifetime), but its flutter stays at normal speed. Restart resets the once-per-user confetti flag.
