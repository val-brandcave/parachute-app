Apollo's credit-usage donut (10, 12) sits over a fixed 100-credit allowance that renews. Ours has no fixed total: the balance is prepaid, so a donut there would make up a denominator. A donut appears only where there is a real finite total, which is spend in a period: 12 credits used in November, split by review type. The balance stays a bar everywhere (popover, Overview runway, sidebar) because a bar answers "how long will this last" and shows what the balance is made of. People get a ranked bar list, because five or more slices can't be read and names need room. An empty period shows one line, with no empty ring.
