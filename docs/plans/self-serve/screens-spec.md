## 0. Reconciled model (what the screens assume)

| Topic | Decision used on the screens | Status |
|---|---|---|
| Unit of account | **Credits, always paired with dollars.** 1 credit = 1 review type on 1 report ≈ **$150 [var]**; full review (Technical + Administrative) = 2 credits ≈ $300 [var]. Chips read `2 credits · ~$300`. Receipts and statements are in dollars. | Rec, for Val |
| Trial | **Free sample review + 3 full reviews = 6 trial credits**, no card. Trial credits are usage-capped, no calendar expiry. | Rec, reconciles the two Nov 4 pages |
| Earned credits | **+1 credit per verified setup step, cap 3 per org.** Steps: upload bank policy; publish a compliance checklist and set it default; publish a custom workbook layout. Alternative: link YouConnect. Invite reward deferred. Never for judgment or volume. Earned credits last 90 days [var]. | Rec |
| Purchased | Packs of 5 / 10 / 20 credits (~$750 / ~$1,500 / ~$3,000 [var]); 12-month life [var]; org_admin only; auto-reload off by default ("below 2, add 10", monthly cap). Spend order: trial → earned → purchased. | Rec |
| Zero balance | Checked at Start review, never mid-run. Blocked state keeps the upload as a held draft; inline top-up; reviewers see "Ask your admin". Reserve at Start, settle at review_ready, refund on our failure. | Rec |
| Sales threshold | Two org-setup questions: reviewers (Just me / 2–10 / 11+) and reports a month (Under 50 / 50–200 / 200+). 11+ or 200+ shows "Talk to us" first and flags sales; self-serve is never blocked. | Agreed direction |
| Activation | Both states designed: instant start (proposed auto-activate rule for card-verified ≤10-seat orgs) and **Pending approval** (Realwired staff, ≤1 business day; sample review usable while waiting). | Open, for Ed |
| Ownership | Keycloak (themed, RWT-1061) owns create account / verify / sign in / reset / MFA. Parachute owns everything after the token. Bouncer owns members, roles, SSO (deep link). Registry/RM own entitlements and price. | Constraint |
| Roles | reviewer · approver · org_admin (production). Only org_admin buys, sees billing, changes payment. | Constraint |
| Checklist | "Getting set up": two short lists (First review · Ready for your team), progress "N of 6", who/when on each done row, only "Account created" pre-ticked, dismissible per user, reopens from Help → Setup guide. | Rec |
| Education | Three 60–90 s user-triggered videos tied to steps + Reviewer Guide / Admin Guide PDFs. No tour on first load. | Rec |
| Celebrations | One quiet toast + a balance tick on an earned credit. No confetti anywhere. Signing = neutral receipt. | Rec |

- Tone: calm, factual, navy CTAs, petrol only for links/AI cues/focus; no gradients, no badges/streaks/confetti, no emoji.
